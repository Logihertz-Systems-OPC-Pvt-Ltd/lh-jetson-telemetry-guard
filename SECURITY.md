# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Logihertz Systems (OPC) Private Limited takes the security of sovereign edge computing, embedded systems, and air-gapped appliances seriously. If you discover a security vulnerability in `lh-jetson-telemetry-guard`, please report it promptly.

### Coordinated Disclosure Channels

- **Primary Contact**: Sameer Tawade (Creator, Founder, Director & Sole Developer)
- **Email**: [`security@logihertz.com`](mailto:security@logihertz.com)
- **Alternate**: [`ops@logihertz.com`](mailto:ops@logihertz.com)
- **PGP Encryption**: Available upon request.

### Information to Include

Please provide:
1. Product name (`lh-jetson-telemetry-guard`) and version (`0.1.0`).
2. Description of the vulnerability (e.g., eBPF bypass, regex evasion in domain sinkhole, unhandled exception in posture auditor).
3. Proof-of-concept payload, policy JSON, or reproduction steps.
4. Impact assessment on air-gapped NVIDIA Jetson L4T / embedded systems.

### Response Timelines

- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Reproduction**: Within 72 hours.
- **Fix & Advisory Release**: Coordinated with the reporter, target within 14 days.

Do NOT open public GitHub issues for undisclosed security vulnerabilities.
